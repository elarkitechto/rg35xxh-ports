# Ports repository

Before adding or replacing any cover, read [docs/COVERS.md](docs/COVERS.md). KNULLI catalogue covers are vertical 2D box art; horizontal 640×480 gameplay belongs in screenshot.png. Validate both media files with tools/validate-port-media.py and inspect the cover visually before deployment.

Follow CONTRIBUTING.md and docs/WORKFLOW.md. Keep APKs, extracted assets, system libraries, saves, credentials and built packages outside Git. Stage only files belonging to the current task; preserve unrelated changes.
