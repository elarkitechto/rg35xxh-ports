# Artwork provenance

The original Threes artwork in `assets/original` and derived textures in
`assets/skin` was extracted from the publicly served web demo at
http://play.threesgame.com/assets.parcel at the user's request for a personal prototype.
`assets/original/provenance.json` records the parcel and resource SHA-256 hashes.

These files are NOT covered by Triples' Unlicense. No permission to redistribute
the original artwork has been established. The public source tree excludes
`assets/original` and `assets/skin`; without them, the game uses code-generated
Triples tiles. Builds containing the original artwork must remain private.

Threes: Sirvo; game design by Asher Vollmer, artwork by Greg Wohlwend.
The fork's synthesized sound effects and fonts are inherited from Triples,
not extracted original Threes audio. Inter and Jua font notices are in `licenses/`.

La versión privada también incluye dos pantallas de inicio derivadas de una
ilustración promocional de Threes publicada en Steam, editadas para mostrar
“Triples” y adaptar la orientación. Permanecen fuera de Git y no se
redistribuyen en el paquete público.
